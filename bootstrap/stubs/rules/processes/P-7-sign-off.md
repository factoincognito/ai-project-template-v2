# Process P-7. Sign-off

P-7 § 1 (C) Sign-off
(1) A project signs off by a PR in that project that makes its `RULES.md` open with: "L § 1 (C) This project is bound by the Rules in `rules/`, in the edition `rules/EDITION` names."

P-7 § 5 The setup PR
(1) The PR that sets the project up is its sign-off: it holds `RULES.md` with `L § 1 (C)`. The setup script opens it and merges it on a green `build`, before any other work on the project; by running the setup, the product owner signs off.
